uFreeTokens 管理员联调页

这是一个手工联调工具，不是生产管理后台——把每一步的原始请求/响应都摊开在下方日志区， 方便直接核对是否成功。所有请求都发到当前这个页面的同源地址（即 cmd/admin），不需要额外配置。

0. 管理员令牌

保存在浏览器 localStorage 里，只用于给后续请求加 Authorization 头，不会发到任何第三方。

1. 接入供应商

Base URL 是从公开文档抄的，各家随时可能调整域名/路径，连不上先去官方文档确认一下。 Provider Code 有唯一约束；重复点击会报错，这是预期行为——换个 Code 或者复用已有的 provider_account_id（见下）。

2. 拉取上游模型列表

3. 导入选中模型

先勾选第 2 步里的模型，再点这个——会自动查两个真实来源有没有现成的成本价 （美元/百万 token）：OpenRouter（GET /api/v1/models，价格直接放在模型列表接口里，优先取它的结果） 和 LiteLLM 社区数据集（BerriAI/litellm 维护的 model_prices_and_context_window.json）。 两个都是精确按模型 ID 匹配，不做模糊猜测——查得到就把成本价填好并在"来源"那列标出是哪个来源；查不到的行成本价留 0，需要自己填 （SiliconFlow 这类只在自己官网发布价格、不进任何聚合数据集的供应商大概率查不到，见前面的排查结论）。 售价 = 成本(USD) × 汇率 × (1 + 利润率)——利润率默认 3%，对齐技术方案 §6.4/§7.9.3 的示例 （采购价 4.5 元、利润 3% → 售价 4.635 元，4.5×1.03=4.635）。改成本、改汇率、改利润率都会实时重算—— 但算出来的售价框仍然是普通输入框，算完之后你还能手动改，改完只要不再碰成本/汇率/利润率就不会被覆盖回去。 汇率和利润率都是占位默认值，不是实时汇率/真实定价策略，改成你自己的数字。
